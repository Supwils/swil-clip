# SwilClip 版本规划（v0 / v1）

本文档约定：**v0 = 当前已交付能力**（以仓库实现为准）；**v1 = 下一阶段的拓展与优化方向**（尚未排期，可随时调整）。

更完整的架构与 IPC 说明见 [init-doc.md](./init-doc.md)。

---

## v0 — 当前能力（Clipboard 核心）

### 产品形态

- macOS 为主场景；托盘常驻、**无 Dock 图标**；窄面板（340×480）、无边框、毛玻璃（vibrancy）。
- **全局快捷键**呼出/隐藏主窗口（默认 `Cmd+Shift+V`，可在设置中修改并持久化）。

### 剪贴板历史

- **后台轮询**系统剪贴板（约 **500ms** 间隔），检测变更后写入本地历史。
- **文本**与**图片**（TIFF/PNG 等 → Base64；列表中缩略图 + 尺寸/格式元信息）。
- **去重**：相同类型 + 相同内容的历史条目会被合并（新拷贝排到最前）。
- **容量**：最多 **50** 条；超出时淘汰最旧条目（与 `MAX_HISTORY` 一致）。
- **置顶（Pin）**：单条可置顶；列表稳定排序为**置顶组在前**，组内保持相对顺序；再次复制已置顶内容会**保留置顶状态**。
- 持久化：`tauri-plugin-store`，与部分应用设置共用存储文件（见实现中的 store 路径）。

### 呼出后的交互

- 基于 **cmdk** 的搜索框（打开即聚焦）、列表导航、`Enter` 将选中项**写回剪贴板**并**模拟 `Cmd+V`** 粘贴到此前前台应用，然后隐藏窗口。
- **粘贴目标恢复**：打开面板前记录 macOS 前台应用，粘贴前尝试切回该应用，减少贴错窗口的概率。
- **快速粘贴**：对列表中**前 9 条**（当前排序下）支持 **`Alt+1` … `Alt+9`**（与 `QUICK_PASTE_LIMIT` 一致）。
- 单条删除、**清空全部**（设置/面板内操作）；部分条目支持**展开**以查看更长文本。
- 顶部**可拖拽区域**移动窗口；窗口**移动后**会防抖写入**上次位置**（下次打开优先使用）。

### 系统托盘

- 菜单：**显示 SwilClip**、**退出**；单击托盘图标也可打开主窗口。

### 设置

- **全局快捷键**字符串解析、注册、持久化（`get_settings` / `update_global_shortcut`）。

### 技术栈（摘要）

- Tauri 2、React 19、Vite 6、TypeScript strict、Tailwind 4、shadcn/cmdk；Rust 侧 `NSPasteboard` + `CGEvent` 模拟粘贴等（详见 init-doc）。

### v0 说明性备注（实现细节）

- 数据模型中含 `appName` 等字段，**当前监听路径多为占位**（便于后续按来源应用筛选等能力）。
- 用户文档（如根目录 README）若与代码快捷键描述不一致，**以代码与本文 v0 为准**，文档对齐可作为小版本修正项。

## v1 — 规划中的拓展与优化

下列条目按主题分组，**不承诺全部实现**；迭代时可再拆成 v1.0 / v1.1 等。

### 产品：从「历史流」到「可策划资产」

- **片段库 / Prompt 库**：与「被动历史」并列或分栏——支持**手动保存**、**标题/别名**、**不受 50 条淘汰**或独立配额。
- **分类与检索**：文件夹、标签、收藏；搜索范围可选（仅历史 / 仅库 / 全局）。
- **模板变量**：如日期、`{{clipboard}}`、选中文本占位符等，粘贴前展开（需定义安全规则与预览）。
- **从剪贴板一键入库**：当前选中历史项「存为片段」并编辑元数据。

### 体验与效率

- **快捷键策略统一**：快速粘贴、库内条目专用热键等与系统冲突的全局梳理；可选「仅复制到剪贴板、不自动 Cmd+V」模式。
- **条目详情**：Markdown / 代码高亮预览；长文本编辑与版本记录（若做库）。
- **可选行为**：忽略指定应用来源、敏感字段不打历史、图片单独配额或压缩策略。

### 系统与工程

- **来源应用名**：在 v0 字段基础上真正写入 `appName`，支持按应用过滤或展示。
- **富文本 / HTML**：是否纳入历史与粘贴策略（与纯文本并存时的优先级）。
- **配置导出/导入**、本地备份路径说明；若未来需要 **iCloud/多端同步**，单独做隐私与冲突设计。
- **平台**：Windows/Linux 剪贴板与焦点模型差异大，属独立里程碑；macOS **公证/notarization** 与分发说明完善。
- **质量**：可访问性（VoiceOver、键盘陷阱）、国际化、自动化测试与 CI 策略补充。

### 文档与发布

- README、init-doc 与实现**持续对齐**（快捷键、命令表、里程碑）；对外更新日志（CHANGELOG）与版本号策略。
