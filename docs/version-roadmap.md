# SwilClip 版本规划（v0 / v1）

本文档约定：**v0 = 当前已交付能力**（以仓库实现为准）；**v1 = 下一阶段的打磨与稳态目标**。

更完整的架构与 IPC 说明见 [init-doc.md](./init-doc.md)。

---

## 产品方向（已锁定）— 非目标 (Non-Goals)

**决策日期：2026-05-28**
**路线：极简纯粹派 / "更现代的 Maccy"**

SwilClip 是一个**被动剪贴板历史工具**，不是 snippet 库、不是 prompt 工作台、不是知识管理工具。我们靠**做得少、做得极致**赢，而不是靠功能数量赢。

### 我们要打磨到行业第一的三件事

1. **340px 浮窗 + 光标处弹出 + vibrancy**——独占的视觉与位置语言，不退让给"居中大窗口"。
2. **键盘优先（cmdk 心智）**——输入即搜索、方向键即导航、Enter 即粘贴；零鼠标也能完整使用。
3. **被动历史的可靠性**——监听不漏、去重正确、Pin 稳定、焦点恢复准、模拟粘贴不丢首字符。

### 明确不做的事 (Non-Goals)

下列条目**任何时候都不应进入 roadmap**。任何"也许我们可以加一下"的讨论都应回到本节。

- ❌ **Snippet / Prompt 库**——这是另一个产品。要做请 fork 出去做。已存在的设计草案 `docs/v1/prompt-manager.md` 已废弃。
- ❌ **模板变量 / 占位符展开**（`{{clipboard}}`、日期、选中文本等）——属于 snippet 范畴。
- ❌ **文件夹 / 标签 / 收藏夹**——50 条历史的本质是"短时记忆"，不应被组织化。要"长期保留"的内容请放到笔记 app。
- ❌ **Markdown / 代码高亮预览 / 长文本编辑器**——我们是粘贴板，不是阅读器，更不是编辑器。
- ❌ **同步（iCloud / 多端 / 团队）**——单机即终态。这也避开了一整类隐私和冲突设计的复杂度。
- ❌ **跨平台（Windows / Linux）**——macOS 原生体验是产品的一部分，不是限制。
- ❌ **AI 功能**（翻译、总结、prompt 推荐、语义搜索）——和定位无关。
- ❌ **富文本 / HTML 保留格式粘贴**——纯文本 + 图片是终态。富文本带来的边界 case 不值。
- ❌ **任何形式的"工作流" / 链式粘贴 / 多剪贴板**——一次一项，键盘流转。

### 判断新需求的三问

任何新需求进入讨论前，先回答：

1. 它是否让"被动捕获 → 搜索 → 粘贴"这条主链路**更快、更稳、更不被打扰**？
2. 它能否在不增加新概念（不需要给用户解释"什么是 X"）的前提下实现？
3. 不加这个功能，用户会**离开**我们去用 Maccy / Raycast 吗？

**三个都是"是"才做。任何一个"否"就拒绝。**

## v0 — 当前能力（Clipboard 核心）

### 产品形态

- macOS 为主场景；托盘常驻、**无 Dock 图标**；窄面板（340×480）、无边框、毛玻璃（vibrancy）。
- **全局快捷键**呼出/隐藏主窗口（默认 `Cmd+Shift+V`，可在设置中修改并持久化）。

### 剪贴板历史

- **后台轮询**系统剪贴板（约 **500ms** 间隔），检测变更后写入本地历史。
- **文本**与**图片**（TIFF/PNG 等 → Base64；列表中缩略图 + 尺寸/格式元信息）。
- **去重**：相同类型 + 相同内容的历史条目会被合并（新拷贝排到最前）。
- **容量**：最多 **50** 条；超出时淘汰最旧条目（与 `MAX_HISTORY` 一致）。
- **置顶（Pin）**：单条可置顶；列表稳定排序为**置顶组在前**，组内保持相对顺序；再次复制已置顶内容会**保留置顶状态**。
- 持久化：`tauri-plugin-store`，与部分应用设置共用存储文件（见实现中的 store 路径）。

### 呼出后的交互

- 基于 **cmdk** 的列表导航 + `s` 进入搜索；`Enter` 触发剪贴板回写并隐藏窗口，行为受 **Auto Paste** 开关控制（见下）。
- **`Enter` 默认（Auto Paste = false）**：把选中项写回系统剪贴板 + 隐藏面板 + 把焦点还给呼出前的前台 App（如 Terminal/编辑器，光标继续闪在原输入框），**不**模拟 `Cmd+V`；用户自行决定何时何处按 ⌘V。该模式无需 Accessibility 权限。
- **`Enter` 开启 Auto Paste 后**：写回剪贴板 + 切回原 App + 模拟 `Cmd+V` 一键贴到原输入框。需要 Accessibility 权限。
- **粘贴目标恢复**：呼出面板前记录 macOS 前台应用 (`focus_target::PasteTargetStore`)；显式关闭路径（Enter / Esc / 再次按全局快捷键）都会显式 `activate_stored_now()`，不依赖 macOS 自动还焦点，避免 panel 窗口 (`decorations:false + alwaysOnTop`) 隐藏后输入框丢光标。
- **快速粘贴**：对列表中**前 9 条**（当前排序下）支持 **`⌥+1` … `⌥+9`** (Option/Alt，与 `QUICK_PASTE_LIMIT` 一致)，行为与 `Enter` 一致并受 Auto Paste 开关影响。
- 单条删除、**清空全部**（设置/面板内操作）；部分条目支持**展开**以查看更长文本。
- 顶部**可拖拽区域**移动窗口；窗口**移动后**会防抖写入**上次位置**（下次打开优先使用）。

### 系统托盘

- 菜单：**显示 SwilClip**、**退出**；单击托盘图标也可打开主窗口。

### 设置

- **全局快捷键**字符串解析、注册、持久化（`get_settings` / `update_global_shortcut`）。
- **历史上限 (`maxHistory`)**：UI 选择 50/100/200/500；后端 clamp 到 [10, 1000]；变更后立即截断超额历史 (`update_max_history`)。
- **Auto Paste 开关 (`autoPaste`)**：默认 **关闭**——Enter 只把选中项写回剪贴板 + 把焦点还给原 App，不模拟 `Cmd+V`；开启后 Enter 直接模拟粘贴（需 Accessibility 权限）。`update_auto_paste`。

### 技术栈（摘要）

- Tauri 2、React 19、Vite 6、TypeScript strict、Tailwind 4、shadcn/cmdk；Rust 侧 `NSPasteboard` + `CGEvent` 模拟粘贴等（详见 init-doc）。

### v0 说明性备注（实现细节）

- 数据模型中含 `appName` 等字段，**当前监听路径多为占位**（便于后续按来源应用筛选等能力）。
- 用户文档（如根目录 README）若与代码快捷键描述不一致，**以代码与本文 v0 为准**，文档对齐可作为小版本修正项。

## v1 — 打磨与稳态目标

v1 **不是**功能扩张，而是把 v0 已有的能力打磨到"行业第一的纯历史剪贴板"。任何看起来像「新功能」的条目都要先通过上方「判断新需求的三问」。

### 主链路：被动捕获 → 搜索 → 粘贴

- **监听可靠性**：500ms 轮询的丢失/重复边界 case 全面测试；切换用户/锁屏/睡眠唤醒后的行为收敛。
- **去重正确性**：图片去重（hash 而非 base64 比较）、超长文本去重的等价性策略。
- **模拟粘贴稳健性**：低性能机、外接键盘、输入法激活态下不丢首字符；Accessibility 权限丢失的清晰引导。
- **焦点恢复准确度**：覆盖更多前台 app 的边界（全屏 app、Spaces 切换、菜单栏 app）。

### 浮窗与交互

- **位置策略**：多显示器下的呼出位置；屏幕边缘的自动避让；保存位置 vs 跟随光标的明确开关。
- **键盘流**：所有操作（Pin、删除、清空、重排）的纯键盘可达性审计；与系统快捷键冲突的全局梳理。
- **空状态 / 首次启动**：第一次按 Cmd+Shift+V 时的引导比现在更克制、更清楚。
- **Auto Paste 引导**：默认关闭的状态对老 Maccy 用户略反直觉，需要在面板底部 ⏎ 标签和设置项里继续打磨"Copy / Paste"两种含义的可见性（已在 footer hint reel 提示，但首启动教学缺位）。

### 系统与工程

- **macOS 公证 (notarization) + 签名 + 自动更新**——这是从"开源工具"走向"可推荐给非技术朋友"的必经之路。
- **来源应用名 (`appName`)**：v0 字段已存在但未真实写入。仅作**展示用途**（"来自 Chrome"），**不做**按应用过滤——那会让产品变重。
- **本地存储健壮性**：store 文件损坏/迁移的容错；可选的导出/导入（纯文本 JSON，仅用于备份，不做同步）。
- **质量基线**：可访问性 (VoiceOver、键盘陷阱)、性能 (大量历史下的搜索 < 16ms)、Rust + TS 自动化测试覆盖核心路径。

### 文档与发布

- README、init-doc 与实现**持续对齐**；对外更新日志（CHANGELOG）与语义化版本号。
- 落地页 / Product Hunt 时机的内容素材准备（截图、30 秒 demo）。
